# Lingua Franca — Landing Page (Vite + React + Tailwind)

Landing page oficial bilingüe (**ES / EN**) para **Lingua Franca** (*Clases de Idiomas 100% Virtuales & Desarrollo Web*).

## Características
- **Tema Oscuro por defecto** con interruptor en vivo a Modo Claro.
- **100% Bilingüe (Español / Inglés)** orientado a audiencias de Colombia y Estados Unidos.
- **Tipografías oficiales:** `Montserrat` (encabezados y botones) y `Quicksand` (cuerpo y formularios).
- **SEO & SEM Optimizado:** Meta tags dinámicos, etiquetas `hreflang`, Open Graph, `sitemap.xml`, `robots.txt` y datos estructurados `JSON-LD` (`Schema.org`).
- **Compatibilidad Multi-navegador:** Probado y compilado para Chrome, Brave, Firefox, Edge, Opera y Safari.
- **Conversión directa a WhatsApp (`+57 350 427 2851`)** con generador inteligente de consulta.

## Instalación y pruebas locales

```bash
npm install
npm run dev
```

## Compilar para producción (Vercel)

```bash
npm run build
```
